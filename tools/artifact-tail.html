The scripting language

Everything the web version ran still runs unchanged. What the parser adds is the things its line-scanning interpreter could not express: loops, chained conditions, and expressions with more than one operator.

How it fits together

The runtime is deliberately free of any DOM or Tauri dependency: it talks to a small host interface. That is what lets the same engine drive the play window and the exported page, instead of maintaining two of them.

src-tauri/ menu.rs native menu bar, emits events to the frontend format.rs .hmango package + .hweb interop, atomic writes src/ runtime/ lexer → parser → AST → async interpreter ← the engine canvas/ surface, flood fill, one module per tool model/ stack, history, document lifecycle editor/ toolbar, inspector, card browser, script editor play/ play window ┐ both drive export/ standalone HTML ┘ runtime/ through one host interface
